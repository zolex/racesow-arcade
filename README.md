# 🏁 Racesow Arcade

**Racesow Arcade** is a 2D arcade interpretation of the classic **Racesow** racing experience. It translates the high-skill, movement-focused gameplay of the original *Racesow* mod for *Warsow* into a fast, precision-driven **2D arcade runner**.

Instead of vehicles, **your character *is* the racer** — mastering momentum, timing, and advanced movement techniques to shave milliseconds off your runs.

Inspired by my former idtech2 project **Racesow** \
👉 https://www.moddb.com/mods/racesow  
👉 https://github.com/Racenet/racesow

## 🎮 Gameplay Overview

Racesow Arcade focuses on **speed, flow, and execution**. Each map is a race against time where learning optimal routes, chaining jumps, and mastering wall interactions is key.

The game rewards:
- Perfect timing
- Momentum preservation
- Creative movement
- Route optimization

Just like in the original Racesow, **milliseconds matter**.

## 🚀 Core Mechanics

- **Running & Speed**  
  Build and maintain speed through precise movement and jump timing.

- **Jumping**  
  Jumping closer to the ground helps to gain and preserve momentum.

- **Wall-Jumping**  
  Use walls to gain height, cross gaps, or redirect speed.

- **Air Control**  
  Adjust direction mid-air to optimize landings.

- **Crouch & Slide**  
  Navigate tight spaces and preserve speed using crouch and slide mechanics.

- **Advanced Techniques**  
  Plasma climbing, plasma sliding, rocket- and double-rocket jumps enable high-skill routes and shortcuts.

## 📦 Installation

### Requirements
- Python 3.x
- Dependencies listed in `requirements.txt`

### Run locally

```bash
git clone https://github.com/zolex/racesow-arcade.git
cd racesow-arcade
pip install -r requirements.txt
python RacesowArcade.pyw
```
